09BmadBrowser

Native macOS browser & editor for BMad artifactsNavigateur et éditeur macOS natif pour les artefacts BMadBMad 產出物的原生 macOS 瀏覽器與編輯器

Browse and edit BMad artifacts without leaving the flow.Parcourez et éditez vos artefacts BMad sans rompre le flux.瀏覽並編輯你的 BMad 產出物，不打斷心流。

A focused 3-column UI — Projects, Documents, Detail — for the markdown the BMad method leaves behind. Native macOS, no Electron.Une UI en 3 colonnes — Projets, Documents, Détail — pour le markdown que laisse la méthode BMad. Natif macOS, sans Electron.三欄式介面——專案、文件、詳細內容——為 BMad 方法留下的 markdown 而設計。原生 macOS，不使用 Electron。

FeaturesFonctionnalités功能

  • Auto-detectionDétection automatique自動偵測

    Finds your projects and the BMad output folder automatically (_bmad/config.toml, docs/, _bmad-output/).Détecte automatiquement vos projets et le dossier de sortie BMad (_bmad/config.toml, docs/, _bmad-output/).自動偵測你的專案與 BMad 輸出資料夾（_bmad/config.toml、docs/、_bmad-output/）。

  • Rich markdownRendu markdown riche完整 markdown 呈現

    Clean markdown rendering with text selection, so you can read and copy from your artifacts naturally.Rendu markdown soigné avec sélection de texte, pour lire et copier vos artefacts naturellement.精緻的 markdown 呈現並可選取文字，讓你自然地閱讀與複製產出物。

  • Image & PDF previewAperçu images & PDF圖片與 PDF 預覽

    Built-in preview for images and PDFs — no need to switch apps to check a diagram or a spec.Aperçu intégré pour les images et les PDF — pas besoin de changer d'app pour vérifier un schéma ou une spec.內建圖片與 PDF 預覽——不必切換應用程式就能確認一張圖或一份規格。

  • Edit & saveÉdition & sauvegarde編輯與儲存

    Edit and save (⌘S) text files — yaml, json, txt, csv, toml, md — right where they live.Éditez et sauvegardez (⌘S) les fichiers texte — yaml, json, txt, csv, toml, md — là où ils se trouvent.就地編輯並儲存（⌘S）文字檔——yaml、json、txt、csv、toml、md。

  • Frontmatter badgesBadges de frontmatterFrontmatter 標籤

    YAML frontmatter surfaced as badges (status, type, date) plus filter by name to find documents fast.Le frontmatter YAML affiché en badges (statut, type, date), avec filtre par nom pour retrouver un document vite.YAML frontmatter 以標籤呈現（狀態、類型、日期），並可依名稱篩選，快速找到文件。

  • Bilingual EN/FRBilingue EN/FR雙語 EN/FR

    Bilingual interface that remembers your last opened project between sessions.Une interface bilingue qui se souvient du dernier projet ouvert entre les sessions.雙語介面，並在不同工作階段之間記住最後開啟的專案。
